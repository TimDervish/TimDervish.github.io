# Privacy policy

Last updated: 16 November 2026

Species uploader is a private tool operated by Studio 256. It uses YouTube API Services to upload videos and set video details (titles, descriptions, tags, thumbnails, playlists, visibility and publishing times) on YouTube channels owned by Studio 256.

**What it accesses.** When a channel owner signs in, the tool receives permission to manage that YouTube channel. It reads the channel's name and ID to confirm it is the right channel, and uploads and edits videos on it. It does not access any other Google data.

**How data is stored.** The sign-in tokens are stored only on computers operated by Studio 256, and are used only to upload and manage Studio 256's own videos. No data is sold, shared with third parties, or used for advertising.

**YouTube and Google.** By using this tool you are also bound by the YouTube Terms of Service (https://www.youtube.com/t/terms) and the Google Privacy Policy (https://policies.google.com/privacy).

**Revoking access.** Access can be removed at any time from your Google Account's security settings (https://myaccount.google.com/connections), after which the tool can no longer access the channel.

**Contact.** For questions, contact Studio 256 through the Species YouTube channel.
